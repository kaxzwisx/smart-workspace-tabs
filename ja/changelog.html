v1.0.0 正式リリース 2026年11月

ワークスペースとタブの管理

  • ローカルワークスペース: 作業ごとに専用のワークスペースを割り当てます。切り替えると、開いているタブを保存して閉じ、同じウィンドウに新しいワークスペースのタブを読み込みます。
  • 初回の自動取り込み: 初めてインストールしたとき、開いている各ウィンドウがデータを失うことなく、すぐに最初のワークスペースになります。
  • スマートな自動保存（約0.5秒）: タブの変更（開く、閉じる、並べ替え、グループ化）は、ウィンドウごとの安全なロックのもとで IndexedDB にリアルタイムで保存されます。
  • タブグループの変換: Chromeのタブグループを、タイトル、色、中のタブを保ったまま、ワンクリックで個別のワークスペースに変換します。
  • ドラッグ＆ドロップ: タブや複数選択したタブを、サイドバーや新しいワークスペースの作成エリアにドラッグできます。

生産性と整理

  • 固定のダッシュボード: 各ウィンドウに常に表示されるタブで、ホーム、ライブラリ、フォルダ、すべてのToDoリストを利用できます。
  • ワークスペースのボード: 開いているタブと、セクションごとに保存したリソースを2列で表示します。メモとタスクはサイドパネルで開きます。
  • ドメインビュー: 同じウェブサイトのタブを絞り込み、一括操作（フォーカス、閉じる、保存、重複の整理）ができます。
  • 重複タブのクリーナー: 完全に一致する重複や、セッションのパラメータを無視して同一と判断できるページを見つけ、閉じる前にプレビューで確認できます。
  • 集中セッション: 内蔵タイマー（15分、25分、50分、またはカスタム）。ほかのワークスペースを薄く表示し、離れようとすると確認し、1日ごとの集中時間を記録します。
  • クイック検索（Alt+S / &cmd;+K): 開いているタブ、閉じたタブ、保存したリンク、タスク、履歴を瞬時にあいまい検索します。

パフォーマンスとメモリの最適化

  • 使っていないタブのスリープ: Chromeネイティブの API でメモリを解放します。スリープまでの時間を設定でき、音声再生中のタブ、固定タブ、許可リストのサイトは保護されます。
  • 復元時のスリープ: 以前のワークスペースのタブはスリープ状態でバックグラウンドに読み込まれるため、ワークスペースを瞬時に切り替えられます。

プライバシー、バックアップ、デザイン

  • 100% ローカルでプライベート: すべてのデータはローカルの IndexedDB に保存され、テレメトリーの収集や外部サーバーへの接続はありません。
  • バックアップエンジン v3: JSON形式での書き出しと読み込み（統合または置き換え）。v1 と v2 のバックアップとの後方互換性があります。
  • 定期的な自動バックアップ: 次のフォルダに定期的に自動でバックアップします: Downloads/Smart-Workspace-Tabs/.
  • デザインとカラーパレット: Grupo Ōkami のアートにインスパイアされた洗練されたティール系パレットのライトモードとダークモード。背景はパターンまたはお好みの画像にカスタマイズできます。
