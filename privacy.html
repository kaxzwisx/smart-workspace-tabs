Privacy Policy

Smart-Workspace-Tabs was engineered from day one with a strict local-first philosophy: your browsing habits, tabs, links, and notes belong to you and never leave your computer.

Last updated: November 2026 · Effective Date: November 2026

1. Summary & Core Principles

Smart-Workspace-Tabs does not collect, transmit, sell, or monetize any of your data. There are no analytics trackers, no telemetry scripts, no third-party cookies, and no backend servers.

The Golden Rule: The extension makes zero external network requests. All workspaces, open tabs, saved links, notes, and task lists live solely inside your browser's local IndexedDB database.

2. Data Storage & Architecture

When you use Smart-Workspace-Tabs:

  • Local Database: All workspaces, tabs, resources, notes, and task lists are stored using the native browser IndexedDB API (via Dexie.js) in your local Google Chrome profile on your computer.
  • Session State: Transient mapping between open browser windows and workspaces is held in Chrome's in-memory chrome.storage.session and is cleared when the browser shuts down.
  • No Remote Sync: There are no cloud accounts, no login screens, and no remote synchronization servers. Data travels only when you explicitly export a JSON backup file to your own hard drive.
  • Content Isolation: The extension does not declare host_permissions and has no content scripts. It cannot read the contents, DOM trees, form fields, keystrokes, or passwords of any webpage you browse.

3. Chrome Permissions & Why They Are Needed

Chrome extensions require explicit permissions in manifest.json to interact with browser APIs. Here is an honest, line-by-line explanation of every permission requested by Smart-Workspace-Tabs:

Permission Classification Why It Is Needed
tabs Required Enables saving, restoring, closing, and reordering tabs when switching workspaces, as well as detecting open URLs for domain views and duplicate cleaner.
tabGroups Required Allows creating, converting, and restoring Chrome native Tab Groups and grouping saved workspace resource sections.
storage Required Stores user preferences (e.g. active theme, tab sleeping idle time, custom background choice) and session window mappings.
unlimitedStorage Required Removes the default 5 MB quota on IndexedDB so you can save large workspace collections, notes, and an optional custom background without errors.
alarms Required Runs background periodic checks for tab sleeping idle timeouts, scheduled to-do task notifications, and automatic daily backup exports.
notifications Required Displays local, offline desktop notifications when a focus session timer ends or when a task due date arrives.
history Required Enables Quick Search (Alt+S) to search across your recent local browsing history and allows adding resources directly from past visits. History data is never exported or sent anywhere.
favicon Required Displays website icons in the dashboard and tab lists using Chrome's built-in local favicon cache, without making external network calls.
downloads Optional Requested only if you explicitly enable automatic periodic backups in Settings › Backup & data to save JSON backups to your Downloads/Smart-Workspace-Tabs/ folder.

4. Data Ownership & Portability

You have 100% control over your data at all times:

  • Export at any time: Go to Settings › Backup & data to download a clean, human-readable .json file containing all your workspaces, resources, notes, and tasks.
  • Import & Merge: You can import backups onto other computers or restore from previous versions without needing a server.
  • Permanent Deletion: Clicking Delete all data in Settings immediately wipes the local IndexedDB database and clears storage completely. Uninstalling the extension also removes all stored data automatically.

5. Third-Party Services

Smart-Workspace-Tabs does not integrate with, transmit data to, or embed any third-party services, analytics suites (such as Google Analytics or Mixpanel), advertising networks, or CDNs. All scripts, stylesheets, and assets are bundled directly inside the extension package.

6. Changes to this Policy

If we make changes to this privacy policy, we will update the "Last updated" date at the top of this page and document the changes in the Changelog. Since we collect no email addresses or contact details, users are encouraged to review this page periodically.

7. Contact & Feedback

Smart-Workspace-Tabs is 100% free and strictly local-first. We are dedicated to complete transparency regarding data handling and privacy.
