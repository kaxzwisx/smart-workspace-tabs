Ayuda y Preguntas Frecuentes

Todo lo que necesitas saber sobre el uso de Smart-Workspace-Tabs, atajos de teclado, ahorro de memoria y gestión de respaldos.

1. Primeros Pasos

Al instalarse, la extensión crea una copia de seguridad automática de cada ventana abierta de Chrome, convirtiéndola en un espacio de trabajo inicial (por ejemplo, "Mis pestañas", "Ventana 2", etc.). Ninguna pestaña se cierra ni se pierde. Además, se crea una pestaña fija del Panel de Control para acceder rápidamente a todas las funciones.

Debido a que Chrome no permite "ocultar" pestañas de forma nativa, la extensión ejecuta un proceso ordenado de cuatro pasos:

  1. Guarda el estado actual de las pestañas y grupos en el espacio activo.
  2. Restaura las pestañas, fijadas y grupos del nuevo espacio seleccionado.
  3. Cierra las pestañas anteriores manteniendo la pestaña fija del Panel activa para no cerrar la ventana.
  4. Pone las pestañas secundarias en modo de suspensión para no consumir memoria hasta que hagas clic en ellas.

Por diseño y seguridad de tus datos, cada espacio de trabajo solo puede estar abierto en una ventana a la vez. Si seleccionas un espacio que ya está en uso en otra ventana, Smart-Workspace-Tabs enfocará dicha ventana y la traerá al primer plano.

2. Conversión de Grupos de Pestañas

Puedes convertirlos fácilmente desde varios accesos:

  • Desde Ajustes › General: pulsa en "Convertir Grupos de Pestañas de Chrome".
  • Desde el aviso superior en la lista de pestañas de cualquier espacio.
  • Desde la biblioteca de espacios en la pantalla de Inicio.

Cada grupo se convierte en un espacio independiente preservando su nombre, etiqueta de color y todas sus pestañas. Las pestañas no agrupadas se mantienen abiertas.

¡Sí! En la vista de tablero puedes arrastrar pestañas individuales o grupos seleccionados directamente sobre cualquier espacio en la barra lateral, o soltarlas en el área "Soltar pestañas aquí" para crear un espacio nuevo al instante.

3. Limpiador de Duplicados y Vistas de Dominio

Dispone de dos métodos de comparación:

  • URL Exacta: Compara pestañas cuya dirección web coincide al 100%.
  • Ignorar Parámetros y Hash: Identifica la misma página incluso si contiene identificadores de sesión o etiquetas de seguimiento (como ?utm_source).

Antes de cerrar nada, una ventana de vista previa muestra qué pestaña se conservará (la fijada, activa o más reciente) y cuáles se cerrarán.

Una Vista de Dominio es una pestaña personalizada dentro de un espacio que aísla un sitio web en particular (como github.com o docs.google.com). Reúne todas las pestañas abiertas o guardadas de ese dominio y subdominios, permitiendo acciones en lote: enfocar, cerrar todas, guardar como recursos o limpiar duplicados específicos.

4. Atajos de Teclado

Atajo Acción Ámbito
Alt + S Abrir ventana de Búsqueda Rápida En cualquier pestaña de Chrome
Alt + D Abrir o enfocar el Panel de Control En cualquier pestaña de Chrome
Ctrl + K / &cmd; + K Enfocar barra de Búsqueda Rápida Dentro del Panel de Control

Esc Cerrar ventana modal, cajón o búsqueda En cualquier diálogo

5. Suspensión de Pestañas y Ahorro de RAM

Utiliza la API nativa de descarte de Chrome. Al suspender una pestaña, el navegador libera la memoria RAM asociada a los procesos JavaScript y renderizado, reduciendo el consumo de ~200-400 MB por pestaña a solo unos pocos kilobytes. La pestaña sigue visible y al hacer clic en ella vuelve a cargar de inmediato.

De forma predeterminada, la extensión nunca suspende:

  • Pestañas fijadas.
  • Pestañas reproduciendo sonido o vídeo (Spotify, YouTube, videollamadas).
  • La pestaña que estás viendo activamente.
  • Cualquier dominio o URL añadida a tu lista de exclusión en Ajustes › Suspensión de pestañas.

6. Respaldos, Exportación y Recuperación

Dirígete a Ajustes › Respaldo y datos en el panel de control.

  • Exportar Respaldo: Descarga un archivo smart-workspace-tabs-backup-AAAA-MM-DD.json.
  • Importar Respaldo: Puedes elegir entre Combinar (añade nuevos espacios sin modificar los actuales) o Reemplazar (restaura la copia íntegra).
  • Respaldo Automático: Guarda copias diarias en tu carpeta local Descargas/Smart-Workspace-Tabs/ sin intervención.

Al reiniciar Chrome, el servicio en segundo plano analiza las ventanas abiertas y las empareja con tus espacios guardados. Si una ventana tiene pestañas que no corresponden a ningún espacio existente, las guarda en un espacio seguro llamado "Pestañas no guardadas", garantizando que nunca pierdas información.
