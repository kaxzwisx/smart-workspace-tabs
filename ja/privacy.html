プライバシーポリシー

Smart-Workspace-Tabs は、ひとつの基本原則に基づいて設計されています。閲覧の習慣、タブ、リンク、メモはすべてあなただけのものであり、あなたのパソコンの外に出ることはありません。

最終更新: 2026年11月・施行日: 2026年11月

1. 概要と基本原則

Smart-Workspace-Tabs は、個人データや閲覧データを収集、送信、販売、収益化することは一切ありません。分析用のトラッカー、テレメトリー用のスクリプト、サードパーティのCookie、拡張機能に関連するバックエンドサーバーは存在しません。

明確な保証: この拡張機能が行う外部へのネットワーク通信は ゼロです。すべてのワークスペース、タブのリスト、メモ、タスクは、ブラウザのローカルの IndexedDB データベースにのみ保存されます。

2. 保存方法とローカルアーキテクチャ

Smart-Workspace-Tabs の使用中:

  • ローカルデータベース: すべての記録は、ブラウザのネイティブ API IndexedDB （Dexie.js を使用）により、お使いのパソコン上の Google Chrome のローカルプロファイルに保存されます。
  • セッションの状態: 開いているウィンドウとアクティブなワークスペースの一時的な対応関係は、Chromeのメモリ上の chrome.storage.session に保存され、ブラウザを閉じると消去されます。
  • リモート同期なし: アカウントやパスワードの作成、クラウド同期は不要です。データが移動するのは、JSON形式のバックアップを手動でダウンロードしたときだけです。
  • コンテンツの分離: この拡張機能は host_permissions を宣言しておらず、コンテンツスクリプトも挿入しません。そのため、ページの内容、フォーム、パスワード、キー入力を読み取ることはできません。

3. Chromeの権限とその理由

Chrome拡張機能は、ブラウザの API を利用するために manifest.json で特定の権限を要求します。それぞれの役割を詳しく説明します:

権限 種類 技術的な理由
tabs 必須 ワークスペースの切り替え時にタブを保存、復元、閉じる、並べ替えるほか、重複の検出やドメインでの絞り込みに使用します。
tabGroups 必須 Chromeのタブグループを作成、変換、復元し、ワークスペースに保存したリソースをまとめるために使用します。
storage 必須 ユーザー設定（テーマ、スリープ時間、表示設定、アクティブなウィンドウの対応関係）を保存します。
unlimitedStorage 必須 標準のストレージ容量の上限を解除し、大量のワークスペース、メモ、カスタム背景画像をエラーなく保存できるようにします。
alarms 必須 使っていないタブのスリープ、タスクのリマインダー、自動バックアップのために、バックグラウンドで定期的にチェックを行います。
notifications 必須 集中タイマーが終了したときや、タスクの期限が来たときに、ローカルの（オフラインの）デスクトップ通知を表示します。
history 必須 クイック検索（Alt+S）で最近のローカル履歴を検索したり、以前に訪れたページをリソースとして追加したりできるようにします。履歴が書き出されたり送信されたりすることはありません。
favicon 必須 Chromeのローカルキャッシュを使ってダッシュボードにサイトのアイコンを表示します。インターネットへの通信は発生しません。
downloads 任意 この権限は 次の場合にのみ 要求されます: 自動バックアップを明示的に有効にしたとき（ 設定 › バックアップとデータ ）。JSONファイルを次のフォルダに保存するために使用します: Downloads/Smart-Workspace-Tabs/.

4. データの所有権とポータビリティ

データはいつでも完全にあなたが管理できます:

  • いつでも書き出し: 設定 › バックアップとデータ から、すべてのワークスペース、リンク、メモ、タスクを含むわかりやすい .json ファイルをダウンロードできます。
  • 読み込みと統合: 外部サービスに頼ることなく、バックアップをほかのパソコンに移したり、以前の状態に戻したりできます。
  • 完全な削除: 設定で すべてのデータを削除 を押すと、ローカルの IndexedDB データベースがすぐに消去されます。Chromeから拡張機能をアンインストールした場合も、保存されたデータはすべて自動的に削除されます。

5. サードパーティのサービス

Smart-Workspace-Tabs は、外部の分析ライブラリ（Google Analytics や Mixpanel など）、広告ネットワーク、テレメトリーサーバーを一切組み込んでいません。すべてのコードとリソースは拡張機能に直接パッケージされています。

6. 本ポリシーの変更

このプライバシーポリシーを更新する場合は、冒頭の日付を変更し、変更内容を 変更履歴に記載します。メールアドレスや連絡先は保存していないため、このページを定期的にご確認ください。

7. お問い合わせ

Smart-Workspace-Tabs は 100% 無料で、完全にローカルで動作します。データの取り扱いとプライバシーについて、透明性を徹底しています。
