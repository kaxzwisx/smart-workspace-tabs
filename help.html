Help & Frequently Asked Questions

Everything you need to know about using Smart-Workspace-Tabs, keyboard shortcuts, memory optimization, and backup management.

1. Getting Started

When first installed, the extension safely snapshots every existing browser window into its own initial workspace (e.g. "My tabs", "Window 2", etc.). None of your open tabs or windows will be closed or lost. A pinned Dashboard tab is created to give you quick access to all workspaces, search, notes, and settings.

Since Chrome does not have an API to hide tabs, switching workspaces executes a smooth four-step sequence:

  1. Snapshots the current window's open tabs and tab groups into its workspace.
  2. Creates the target workspace's tabs, pinned tabs, and tab groups in the same window.
  3. Closes the previous tabs while keeping the pinned Dashboard tab alive so the window never closes.
  4. Puts restored background tabs into sleep mode to avoid consuming memory until clicked.

By design, each workspace can only be open in one window at a time to prevent accidental data overwrites and tab conflicts. If you select a workspace that is already active in another window, Smart-Workspace-Tabs will smoothly focus that window and bring it to the foreground.

2. Converting Chrome Tab Groups

You can convert tab groups into workspaces in several ways:

  • From the Settings › General tab: click "Convert Chrome Tab Groups".
  • From the banner in the Tabs list inside any workspace.
  • From the Home screen workspace library.

Each group becomes an independent workspace retaining the group's name, color tag, and internal tabs. Ungrouped tabs stay open in your current window.

Yes! Inside the dashboard board view, you can drag individual tabs or multiple selected tabs directly onto any workspace in the sidebar. You can also drop tabs onto the "Drop tabs here" zone to create a brand-new workspace instantly, or use "Move tab to..." in the toolbar popup.

3. Duplicate Tab Cleaner & Domain Views

The cleaner offers two modes of matching:

  • Exact URL: Matches tabs whose full URL is 100% identical.
  • Ignore Query & Fragment: Matches tabs of the same webpage even if they differ by session IDs, tracking tokens (like ?utm_source), or anchor hashes (#section).

Before closing anything, an interactive preview shows which copy is kept (the pinned, active, or most recently used tab) and which will be closed.

A Domain View is a custom tab inside a workspace that isolates a specific website (such as github.com or docs.google.com). It displays all open or saved tabs matching that domain (including subdomains), and provides convenient bulk operations: focus on those tabs, close all of them, save them all as resources, or clean up duplicates for that specific domain.

5. Tab Sleeping & Performance

Tab Sleeping uses Chrome's native tab discarding API. When a tab is discarded, Chrome unloads the heavy JavaScript engine, DOM tree, and render processes from RAM, reducing memory usage from ~150-400 MB per tab to just a few kilobytes. The tab stays in your tab bar, and clicking it reloads its content instantly.

By default, Smart-Workspace-Tabs never discards:

  • Pinned tabs.
  • Tabs currently playing audio or video (e.g. Spotify, YouTube, Google Meet).
  • The active tab you are looking at.
  • Any custom domains or URL patterns you add to the exclusion list in Settings › Tab sleeping.

6. Backups, Export & Data Recovery

Navigate to Settings › Backup & data inside the dashboard.

  • Export Backup: Downloads a single smart-workspace-tabs-backup-YYYY-MM-DD.json file.
  • Import Backup: Allows you to choose between Merge (adds new workspaces without touching existing ones) or Replace (restores exact backup snapshot).
  • Auto-Backup: Automatically saves daily backup files into your browser's Downloads/Smart-Workspace-Tabs/ directory.

Yes. The backup engine uses Schema Version 3 (which added custom backgrounds and focus logs). It includes full backward compatibility for v1 and v2 backups and automatically migrates your records seamlessly upon import.

When Chrome restarts, the extension's background recovery service activates. It analyzes open windows and matches their tab URLs to your saved workspaces. If a window has tabs that do not match an existing workspace, they are automatically saved into a new "Unsaved tabs" workspace so you never lose any work.
