Changelog

Track updates, feature additions, and performance improvements across all versions of Smart-Workspace-Tabs.

v1.0.0 Initial Release November 2026

Workspaces & Tab Management

  • Local Workspaces: Dedicated workspace per project or task. Switching workspaces automatically saves and closes current tabs, restoring the target workspace in the same window.
  • First-Run Auto Import: Every open window is automatically snapshotted into its own initial workspace on first install.
  • Debounced Autosave: All tab modifications (opening, closing, moving, grouping, navigating) are debounced and saved within ~0.5 s with per-window locks.
  • Convert Chrome Tab Groups: One-click conversion of existing Chrome native tab groups into independent workspaces, preserving group names and colors.
  • Drag & Drop: Move individual or multi-selected tabs onto sidebar workspaces or "Drop tabs here" zone to create a new workspace.

Productivity & Organization

  • Pinned Dashboard: Persistent full-screen dashboard tab in each window featuring Home, Library, Folders, and To-Dos.
  • Workspace Board: Side-by-side view of active open tabs, saved project resources, notes drawer, and task checklist.
  • Domain Views: Dedicated views to follow specific sites (e.g. github.com) with bulk actions (focus, close all, save as resources, clean duplicates).
  • Duplicate Tab Cleaner: Identifies duplicate tabs across workspaces or all windows using exact URL matching or query/hash-stripped matching with interactive preview.
  • Focus Sessions: Built-in local timer (15, 25, 50 min or custom), dimming background workspaces, exit confirmation guard, and daily focus time tracking.
  • Quick Search (Alt+S / &cmd;+K): Fuzzy search via Fuse.js across active tabs, closed workspace tabs, resources, tasks, and history.

Performance & Memory

  • Tab Sleeping: Leverages Chrome native tab discarding to free RAM on idle tabs. Supports thresholds, exclusion of pinned tabs, active audio, and customizable domain whitelists.
  • Sleeping on Restore: Restored tabs from previous workspaces remain asleep until clicked, making workspace switching instant.

Data, Privacy & Customization

  • 100% Local & Private: Data stored in IndexedDB (Dexie.js). No account required, zero network requests, no analytics.
  • Backup & Export v3: Full JSON backup export and import (Merge or Replace modes) with backward compatibility for v1 and v2 formats.
  • Automatic Backups: Optional automated export to Downloads/Smart-Workspace-Tabs/ using alarms.
  • Branding & Theming: Light and dark modes styled with the Grupo Ōkami teal color palette. Customizable background pattern or uploaded image with adjustable dimming.
Upcoming In Development Future Roadmap
  • Configurable keyboard shortcuts for quick workspace cycle switching.
  • Enhanced export formats (Markdown list export for workspace resources and notes).
  • Extended workspace color themes and custom icon upload.
  • Domain view regex and wildcard matching rules.
